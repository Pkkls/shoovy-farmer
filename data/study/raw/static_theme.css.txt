/* ============================================================================
   OPERATIONAL THEME — shared across every page.

   Dark, dense, mission-control: near-black surfaces, hairline structure, one
   electric accent (cyan), monospace for anything that is a number. The shell
   is a fixed command bar across the top and a persistent nav rail down the
   left; nav.js builds the markup for both, this file owns their looks.

   Tokens below are the single source of truth. The older names (--blue*,
   --panel2, --gold …) are kept as aliases so page-level <style> blocks keep
   working — change a colour here and it moves everywhere.
   ========================================================================= */
